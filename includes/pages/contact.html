Contact Us — Corrections, Questions and Takedowns

There is no form here, because a static site with a form needs a third-party form service — and that would mean collecting data this site otherwise never touches. Just email.

Email channel

⚠ The contact address is not published yet. It is tied to this site’s final domain, which has not been set — so rather than print an address that goes nowhere, the site operator needs to configure CONTACT_EMAIL before this page can hand you a working one (exact step in the project README, “Setting up the contact address”). Everything else on this page still applies to that inbox.

What to write about

Corrections

Found a control, date or claim that does not match the official source? Send the page URL, the sentence in question and a link to what the official host currently says. Corrections backed by the host’s own page get priority — this site’s value is being right.

Copyright and takedown requests

This site publishes original writing, original illustrations and an original mini-game; it does not re-upload game files, screenshots or other copyrighted game assets. If you represent a rights holder and believe something here infringes your work, write with:

  • the exact URL(s) in question,
  • what you own and how the material is used on the page,
  • a way to reach you for the confirmation reply.

Legitimate requests result in the material being removed or adjusted promptly — no runaround. The same inbox handles licensing conversations, including permission to embed a game: if the rights holder wants the official game loaded here, that is exactly what the built-in embed slot is for.

Everything else

Broken links, a game host that has moved, suggestions for a guide that is missing — all welcome at the same address. If you are a player stuck in a specific level, include the game version (1, 2, 3 or 3D) and what you have tried; the troubleshooting page may answer it faster than we can.
