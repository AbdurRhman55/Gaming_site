Privacy Policy: What This Site Collects (Very Little)

This policy describes the site exactly as it is built — no templates, no promises about features that do not exist. Last updated: 21 October 2026.

The short version

  • No visitor accounts, no forms, no mailing list.
  • Two simple counts kept for the operator — how often pages load and how often game frames open — plus no advertising, no third-party trackers, and no cookies for visitors.
  • Local storage only: your best results in the on-site games, saved in your own browser.
  • Nothing loads from third parties in the background — a game frame loads when you open its game page, and links load only when you click them.

Because no non-essential cookies or storage are used for visitors, there is no consent banner — there is nothing for you to consent to.

What this site stores

Local storage (your device, your browser)

The parking game Tight Lot saves your best time per lot under the keys pfguide.tightlot.best.1, pfguide.tightlot.best.2 and pfguide.tightlot.best.3. The endless game Traffic Rush saves its best distance under pfguide.trafficrush.best.1. This data never leaves your browser — there is no request that transmits it. To remove it, clear site data for this domain in your browser settings; the games work normally without it.

Cookies (one, for the site operator only)

The public site sets no cookies. The operator-only dashboard at /admin/ sets a single session cookie named pf_admin so the operator stays signed in; it expires after seven days, is an HMAC-signed value, and is never used for tracking or shared with anyone. Visitors never receive it.

Simple counts (this site’s own)

A tiny first-party script, part of this site’s own code, tells this site’s server when a page finished loading and when a game frame opened. The server stores only three things: the date, the page path (or game), and how often — no IP address, no cookie, no identifier, nothing about you. The purpose is narrow and stated plainly: the operator compares these totals against Google Search Console and AdSense, which is why they must be accurate rather than estimated. Nothing is shared with anyone, admin pages are excluded, and a visit without JavaScript simply is not counted — the counter only records what it actually sees.

Server logs (your hosting provider)

Like almost every website, the server that delivers these pages keeps standard access logs: IP address, requested URL, time, and browser user-agent. Those logs are created and retained by whichever provider hosts the deployed site, under that provider’s policy. This project ships no logging code of its own. If you need a log-related request handled, start through the contact page.

What this site does not do

  • No cookies for visitors — the only cookie this site sets is the operator’s dashboard session, described above.
  • Only first-party counts — the small same-origin counters described above, and nothing else: no heatmaps, no advertising IDs, no third-party analytics.
  • No advertising and no ad networks.
  • No fingerprinting, no device profiling, no cross-site identifiers.
  • No third-party scripts load in the page background.

Third-party content you choose to open

Pages link to the licensed game hosts (Coolmath Games, Poki) and other sites. Following one takes you there, whose own privacy policy then applies.

In the games library, opening a game page loads that game inside an iframe on the page. The frame is served by the game’s provider domain — games published by this site’s own code load from this domain instead — and may set its own cookies or storage under its policy; this site cannot see or control that. The version-guide pages load nothing from a third party at all: their game panels stay empty and point to the licensed hosts. Nothing third-party loads in the page background anywhere.

Children’s privacy

This site collects personal information from no one, which includes children. There is no visitor account system, no chat, no upload and no way to submit personal data through the site itself — the contact page opens your own email client instead of a data-collecting form.

Changes to this policy

If the site ever gains a feature that changes this footprint — a form, any measurement — this page will be updated to match before the feature ships, and the date above will move. A policy that describes a different site than the one running is worse than no policy.

Questions

Anything about your data or this policy can go through the contact page. Context on why the site is built this way is on the about page.
